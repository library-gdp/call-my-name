# 플러그인 Skill 테스트

## 필요한 이유

`call-my-name` 플러그인의 특정 Skill을 실제로 사용해 나온 결과물을 보존해야 다른 Agent가 그 결과물을 독립적으로 평가할 수 있다. 이 Skill은 실행과 결과물 저장만 담당하여 테스트와 평가의 책임을 분리한다.

## 입력

다음 입력을 확인하라.

- 테스트 대상 Skill의 이름 또는 `call-my-name/skills/` 아래 경로
- 대상 Skill에 그대로 전달할 테스트 요청
- 테스트 요청에 필요한 입력 파일 또는 디렉터리
- 선택 사항인 결과 저장 디렉터리

대상 Skill이나 테스트 요청이 없으면 임의로 정하거나 만들어 내지 말고 사용자에게 필요한 입력을 요청한 뒤 중단하라. 입력 자료가 대상 Skill의 수행에 필수인데 제공되지 않은 경우에도 합성 자료로 대체하지 마라.

## 실행 절차

### 1. 대상 확인

1. 저장소 루트를 기준으로 대상의 실제 경로가 `call-my-name/skills/<skill-name>/SKILL.md`인지 확인하라.
2. 대상이 이 경로 밖에 있거나 `SKILL.md`가 없으면 실행하지 마라.
3. 대상 `SKILL.md`를 처음부터 끝까지 읽어라.
4. 대상 Skill이 수행에 필요하다고 지시한 `references/`, `scripts/`, `assets/`와 명시적 종속 항목만 추가로 불러와라.

### 2. 실행 공간 준비

1. 사용자가 결과 저장 디렉터리를 지정했으면 그 경로를 `RUN_DIR`로 사용하라.
2. 지정하지 않았으면 `__workspace__/agent/plugin-skill-test/<skill-name>/runs/<NNN>/`을 `RUN_DIR`로 사용하라. `<NNN>`은 기존 숫자 디렉터리 다음의 세 자리 번호이며 첫 실행은 `001`이다.
3. `RUN_DIR/workspace/`와 `RUN_DIR/artifacts/`를 만들라.
4. 제공된 입력 자료를 변경하지 마라. 대상 Skill이 입력을 변경할 수 있으면 상대 구조를 유지해 `RUN_DIR/workspace/`에 복사하고 복사본을 사용하라.
5. 테스트 요청을 내용 변경 없이 `RUN_DIR/request.md`에 저장하라.

### 3. 대상 Skill 직접 사용

1. 저장된 테스트 요청을 사용자의 실제 요청으로 취급하라.
2. 대상 Skill의 절차, 규칙, 도구 사용법과 출력 형식을 그대로 따라 처음부터 끝까지 수행하라.
3. 대상 Skill이 명시적으로 요구하지 않은 별도 Skill, 평가 기준, 개선 절차 또는 보완 지침을 추가하지 마라.
4. 대상 Skill의 동작을 더 낫게 만들기 위해 요청을 재해석하거나 결과를 보정하지 마라.
5. 대상 Skill이 추가 사용자 입력을 요구하거나 수행이 차단되면 추측하지 말고 그 상태에서 멈추라.

### 4. 결과물 저장

1. 대상 Skill이 생성한 파일을 `RUN_DIR/artifacts/`에 원형 그대로 보존하라. 대상 Skill이 정한 다른 경로에 파일이 생성되었으면 원본 경로를 유지하고 변경 없이 복사본을 보존하라.
2. 대상 Skill의 결과가 텍스트뿐이면 사용자에게 전달할 결과 원문을 `RUN_DIR/artifacts/result.md`에 저장하라.
3. `RUN_DIR/execution.md`에 다음 실행 사실만 기록하라.
   - 대상 Skill 이름과 경로
   - 테스트 요청 파일과 입력 자료 경로
   - 실제로 읽은 대상 Skill의 참조 파일
   - 사용한 도구와 실행한 명령
   - 생성된 결과물의 경로
   - 발생한 오류 또는 차단 사유
4. 마지막 응답에는 `RUN_DIR`, `execution.md`, 저장한 결과물의 경로만 간결하게 알려라.

## 책임 경계

- 결과의 품질, 정확성, 요구사항 충족 여부 또는 대상 Skill의 구현을 평가하지 마라.
- 기대 결과와 실제 결과를 비교하거나 점수, `PASS`·`FAIL`, 개선 의견 또는 수정 권고를 작성하지 마라.
- 대상 Skill, 플러그인 소스와 원본 테스트 입력을 수정하지 마라.
- 실행 오류나 차단 사유를 해결한다는 이유로 대상 Skill의 지시를 변형하지 마라.
- 평가 자료, 정답 예시 또는 이전 평가 결과를 실행 입력에 섞지 마라.
- 테스트 결과의 평가는 이 Skill의 범위 밖이며 다른 Agent의 책임으로 남겨라.
